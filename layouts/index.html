featured build

把远端 Agent 接到本机 Chrome

openclaw-browser-bridge-portable

一个 Windows 便携桥接器，让 Agent 使用你的本机浏览器上下文。

远端 Agent 可以继续在云端执行推理与工具调用，浏览器动作则通过 Gateway 路由到本机 Chrome。它保留登录态、cookie、缓存和本机网络环境，同时把安全边界限制在浏览器可见页面自动化上。
